MVP 画面遷移フロー — 受験者と企業の体験

最小構成（MVP）で「AI面接を受験 → 文字起こし → スコア付きレポートを確認」までの流れを、 受験者目線・企業側目線それぞれの画面イメージで示します。スマホ＝受験者、PC＝企業の管理画面です。

全体像（1サイクル）

企業が招待し、受験者がAI面接を受け、企業が結果を見て合否を決める——この往復が1サイクルです。

🏢
① 企業：招待求人・質問を設定し、候補者へ招待メールを送る
→
🧑‍💻

→
📊

受験者（面接を受ける人）の体験

スマホ／PCのブラウザで完結。アプリのインストールは不要。

1招待メールが届く

「面接のご案内」メールのリンクをタップ。ログインは招待リンク方式で手間なし。

→
2同意＆機材チェック

プライバシー・録画への同意と、カメラ／マイク／回線のセルフチェックを1画面で。

→
3顔写真で本人確認

顔写真を撮影して本人記録（替え玉の抑止）。MVPでは高度な不正検知は省略。

簡易版
→
4AI面接（フェーズ制）

フェーズごとにAIが質問→受験者が話して回答。交互ターン制で録画。中核体験。

中核 / ターン制
→
5受験完了

完了画面を表示。結果は企業の選考後に通知される運用（MVPはマイページ省略）。

🏢

企業（採用担当）の体験

PCの管理コンソールで、設定・招待・結果確認まで完結。

1管理画面にログイン

採用担当が管理コンソールへ。シングルテナント認証（MVPは細かな権限管理は省略）。

→
2求人・質問セット設定

求人と質問セットを用意（簡易設定）。氷山モデル等の高度な評価軸は将来対応。

→
3候補者を招待

候補者のメールアドレス宛に招待リンクを自動送信。ここで受験者フロー①へつながる。

→
4受験状況を一覧で確認

誰が受験済／受験中／未受験かを一覧で把握。母集団の進捗が見える。

→
5結果レポートを確認

録画再生・文字起こし・LLM要約・簡易スコアを1画面で確認。該当箇所にジャンプ可。

→
6合否を判断

レポートを根拠に担当者が合否を判断。AIは“判断材料の提示”まで、決定は人が担う。

MVPで省いている体験（フェーズ2以降）： 氷山モデルによるコンピテンシー可視化、視線・打鍵音などの高度な不正検知、5W2Hの動的深掘り、候補者の比較・ランキング・合議ワークフロー、 多言語UI、受験者マイページ、ATS／カレンダー連携、マルチテナント＆細粒度の権限管理。 まずは上記のコア体験をリリースして検証し、ここに段階的に上乗せしていきます。
